# easynet
This is the code for easynet. A few notes:
* the files `preprocessing.py` and `au_pro.py` are identical to those in my M3DM repository;
* I have modified `mvtech3d_dataset.py` by adding a function;
* since the complete code is not available on GitHub, my implementation attempts to replicate what is described in the DRAEM paper and repository, from which easynet draws some inspiration. For this reason, the results do not match (unlike in M3DM); in fact, there is a drop in performance.
